# snap flights

Imagine going somewhere but paying 2x less.

Flight search with **price prediction as the headline feature**: book now or wait, what the
price will do next, and how to get it cheaper than anywhere else.

## Status

Spec phase. No implementation yet. Start at **[`specs/README.md`](specs/README.md)**.

- `specs/L0-foundation.md` — the contracts every agent must follow (read first)
- `specs/epics/` — E1 data pipeline and E2 prediction specced in depth; E3–E8 stubbed
- `specs/subfeatures/` — the MVP spine, one spec per agent-sized piece

MVP spine: collect fares → store snapshots → baseline prediction → show buy-vs-wait.
